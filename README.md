# CalculadoraJava
En este repositorio se verán los detalles de la calculadora que he realizado en apacheNetbeans a partir de un jFrame.
La aplicación permite realizar operaciones básicas (+, -, *, /), usar constantes como **π** y trabajar con funciones trigonométricas (**sin, cos, tan**) en **grados y radianes**.  
Incluye además funciones de borrado (**DEL**) y limpieza (**C**).
